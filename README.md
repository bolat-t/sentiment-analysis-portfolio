# 🎭 Advanced Sentiment Analysis Project

A comprehensive sentiment analysis toolkit implementing multiple AI/ML approaches for text sentiment classification. This project demonstrates various techniques from traditional ML to modern transformer models.

## ✨ Features

- **Multi-Model Approach**: VADER, TextBlob, and Transformer-based models
- **Real-time Data Collection**: Automatic data downloading and processing
- **Interactive Visualizations**: Beautiful charts and sentiment distributions
- **RESTful API**: Flask-based API for real-time predictions
- **Comprehensive Testing**: Unit tests and model evaluation
- **Production Ready**: Clean, modular, and well-documented code
